## 1. 问题

当前「数据统计」页面（Dashboard）是纯数据分析视角——KPI 数字 + 图表，缺乏叙事感和回顾价值。用户无法：

- 以「一次外出拍摄」为单位回顾拍摄历程
- 记录拍摄时的天气、地点、心得
- 把精选照片组成一个故事
- 像翻日记本一样浏览自己的拍摄历史

## 2. 目标

将「数据统计」**完全替换**为「拍摄日记」——以一次完整的外出拍摄会话为粒度，用翻页日记本的形式回顾拍摄历程。

---

## 3. 需求详情

### 3.1 会话检测

| 项 | 决策 |
|---|---|
| 算法 | 按天 + 时间间隔聚类：同一天内，相邻照片间隔 > N 小时则切分新会话 |
| 默认阈值 | 4 小时 |
| 可配置 | 是，在设置页中可调整 N 值 |

**理由**：按天 + 间隔能区分「上午拍鸟、晚上拍星」和「通宵拍深空跨午夜」的场景。

### 3.2 日记页布局

```
┌──────────────────────────────────────────────┐
│  2026年3月15日  ☀️ 晴  浙江省杭州市临安区天荒坪  │  头部：日期 + 天气 + 地点
│                                              │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│  │ 📷 │ │ 📷 │ │ 📷 │ │ 📷 │ │ 📷 │  ...   │  精选照片网格
│  └────┘ └────┘ └────┘ └────┘ └────┘        │
│                                              │
│  今晚终于拍到了猎户座大星云，导星很稳...        │  用户笔记
│                                              │
│  拍摄 47 张 | 2 个目标 | 累计曝光 1.5h        │  底部统计条
└──────────────────────────────────────────────┘
```

### 3.3 精选照片

| 项 | 决策 |
|---|---|
| 自动精选 | 按评分最高前 N 张（默认 5 张），无评分则均匀采样 |
| 手动管理 | 用户可增减精选照片 |
| 交互 | 点击照片跳转 Lightbox 预览 |

### 3.4 位置信息

| 项 | 决策 |
|---|---|
| 来源 | EXIF GPS 自动解析 + 用户手动输入 |
| 覆盖关系 | 两种来源可互相覆盖 |
| 依赖 | 扩展 ExifReader 解析 GPS 标签，反地理编码（高德 API / Nominatim） |

### 3.5 天气信息

| 项 | 决策 |
|---|---|
| 来源 | 天气 API 自动获取 + 用户手动修改 |
| API | Open-Meteo Archive（免费，无需 Key，支持历史回溯） |
| 可配置 | 设置页预留 API Provider 切换位 |
| 手动修改 | 点击天气区域弹出天气图标选择器 |

### 3.6 笔记

- 纯文本多行编辑，失焦自动保存

### 3.7 会话管理

| 操作 | 行为 |
|---|---|
| 合并 | 多选两个会话 → 合并为一个 |
| 拆分 | 在会话中选一张照片作为分割点 → 拆为两个 |
| 删除 | 仅删除会话元数据，照片回到"未归类" |
| 手动创建 | 新建空白会话，手动指定起止时间，选择照片归入 |

### 3.8 翻页与导航

| 项 | 决策 |
|---|---|
| 翻页方式 | 左右箭头按钮 + 键盘左右方向键 |
| 快速跳转 | 底部时间轴 |
| 默认页面 | 打开日记本显示最新一次拍摄 |
| 封面/目录 | 不需要，直接进入最近日记页 |

### 3.9 跳转

- 点击精选照片 → Lightbox
- 点击底部统计中的目标标签 → Gallery 按标签筛选
- 点击日期 → Gallery 按日期筛选

## 4. 与旧 Dashboard 的关系

| 项 | 决策 |
|---|---|
| Dashboard | 全部移除（KPI 卡片、热力图、柱状图、排行榜、参数分布） |
| 侧边栏入口 | 「统计」→「日记」，图标替换 |
| 快捷键 | Ctrl+5 保持，跳转到日记页 |

---

## 5. 边界与空态

| 状态 | 表现 |
|---|---|
| 无任何照片 | 「导入照片后，拍摄日记将自动生成」 |
| 有照片但未聚类 | 「正在生成拍摄日记...」+ 加载动画 |
| 只有一次拍摄 | 不显示翻页箭头，时间轴只有一个点 |
| 照片无 GPS | 地点留空，用户手动输入 |
| 天气 API 无数据 | 天气留空，用户手动选择 |
| 照片无评分 | 自动精选改为均匀采样 |
| 会话删除后 | 翻到前一页或后一页 |
