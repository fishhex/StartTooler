# S04 Phase 1 — UploadServerService 核心改造（Token → Secret）

> 关联：`spec/04-pc-v0.14.md`（主规格）、`demand/00-pc-app.md`（需求）

---

## 目标

将 `UploadServerService` 从 v0.12 的 6 位数字 Token 改造为 v0.14 的 32 字符 hex secret，实现：

1. 启动时从 `config.db.upload_secret` 读取；不存在 / 非法 → 生成 + 写回
2. 受保护端点接受 `?k=` 或 `X-Key`（替换 `?token=` / `X-Token`）
3. UI 点「重置密钥」→ 重生成 + 写回 db
4. HealthResponse / UDP 广播字段名 `token` → `secret`
5. 错误码文案 `invalid token` → `invalid secret`

**本阶段不涉及**：ViewModel / View 改动（Phase 2）、版本号升级（Phase 3）。

## Step 2: LoadOrGenerateSecret 实现

**文件：** `StartTooler/Services/UploadServerService.cs`

新增静态方法（L36 附近）：

```csharp
private static string LoadOrGenerateSecret(IConfigService configService)
{
    string? stored = null;
    try
    {
        stored = configService.GetAsync<string>("upload_secret").GetAwaiter().GetResult();
    }
    catch (Exception ex)
    {
        Debug.WriteLine($"[UploadServer] Read upload_secret failed: {ex.Message}");
    }

    if (!string.IsNullOrEmpty(stored) && IsValidSecret(stored))
    {
        Debug.WriteLine($"[UploadServer] upload_secret loaded from config.db (len={stored.Length})");
        return stored;
    }

    // 不存在 / 非法 → 重生成 + 写回
    var fresh = GenerateSecret();
    try
    {
        configService.SetAsync("upload_secret", fresh).GetAwaiter().GetResult();
        Debug.WriteLine($"[UploadServer] upload_secret generated and persisted to config.db");
    }
    catch (Exception ex)
    {
        Debug.WriteLine($"[UploadServer] Persist upload_secret failed: {ex.Message}");
        // 即便写失败，也返回新生成的（内存能用，下次启动重生成）
    }
    return fresh;
}

private static bool IsValidSecret(string s)
{
    return !string.IsNullOrEmpty(s)
        && s.Length == 32
        && Regex.IsMatch(s, "^[a-f0-9]{32}$");
}
```

### 2.1 新增 using

```csharp
using System.Security.Cryptography;
using System.Text.RegularExpressions;
```

### 2.2 GenerateSecret 实现

```csharp
private static string GenerateSecret()
{
    var bytes = new byte[16];
    RandomNumberGenerator.Fill(bytes);
    return Convert.ToHexString(bytes).ToLowerInvariant();
}
```

> 删除旧 `GenerateToken()` 方法。

## Step 3: 重置密钥（RegenerateSecret）

**文件：** `StartTooler/Services/UploadServerService.cs`

替换旧 `RegenerateToken`（L173-179）：

```csharp
// v0.12
public void RegenerateToken()
{
    _currentToken = GenerateToken();

    Debug.WriteLine($"[UploadServer] Token regenerated: {_currentToken}");

// v0.14
public void RegenerateSecret()
{
    var fresh = GenerateSecret();
    _currentSecret = fresh;
    try
    {
        _configService.SetAsync("upload_secret", fresh).GetAwaiter().GetResult();
        Debug.WriteLine("[UploadServer] Secret regenerated and persisted to config.db");
    }
    catch (Exception ex)
    {
        Debug.WriteLine($"[UploadServer] Persist regenerated secret failed: {ex.Message}");
    }
    OnSecretChanged?.Invoke(_currentSecret);
}
```

## Step 4: ValidateSecret（替换 ValidateToken）

**文件：** `StartTooler/Services/UploadServerService.cs`

替换旧 `ValidateToken`（L186-194）：

```csharp
private bool ValidateSecret(HttpListenerRequest request)
{
    // 优先 query 参数 ?k=
    var secret = request.QueryString["k"];
    // 备选 header X-Key
    if (string.IsNullOrEmpty(secret))
        secret = request.Headers["X-Key"];
    return !string.IsNullOrEmpty(secret) && secret == _currentSecret;
}
```

> **删除旧 `ValidateToken` 方法**。

## 验收标准

### 9.1 编译

- [ ] `dotnet build` 通过
- [ ] 无 `_currentToken` / `CurrentToken` / `OnTokenChanged` / `GenerateToken` / `RegenerateToken` / `ValidateToken` 残留（grep 验证）

### 9.2 运行

- [ ] 新装 PC 启动 → `config.db.upload_secret` 有 32 字符 hex 值
- [ ] 第二次启动 → 读到的 secret 与第一次一致（持久化生效）
- [ ] curl `GET /api/v1/health` → 返回 `"secret"` 字段（无 `"token"`）
- [ ] curl `GET /api/v1/projects?k={secret}` → 200
- [ ] curl `GET /api/v1/projects?k=wrong` → 401 `{"error":"invalid secret"}`
- [ ] curl `GET /api/v1/projects?token={secret}` → 401（query 字段名变了，旧 token 不识别）
- [ ] UI 调 `UploadServerService.RegenerateSecret()` → db 中值变化 + 事件触发

### 9.3 临时回滚路径

如果本 Phase 引发回归，临时方案：

```bash
git revert <commit-of-phase1>
```

回滚后 PC 端回到 v0.12 行为（不持久化、6 位 Token）。
