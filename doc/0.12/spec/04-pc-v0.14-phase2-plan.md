### 2.2 新增 MaskSecret 帮助方法

```csharp
private static string MaskSecret(string s)
{
    if (string.IsNullOrEmpty(s) || s.Length < 8) return "****";
    return $"{s[..4]}****{s[^4..]}";
}
```

> KB §十六规定日志脱敏 `12****56` 形式（32 字符场景下用 `7f3a****2c8e`）。

## Step 4: BuildDisplayUrl 改造

**文件：** `StartTooler/ViewModels/UploadServerViewModel.cs`

### 4.1 当前实现

需要先看现有 `BuildDisplayUrl` 实现细节（可能用 `_server?.UploadUrl` + host 替换）。

> 当前代码 `UploadUrl` 是 `$"http://{GetLocalIp()}:{Port}/upload"`，且 `OnAddressIndexChanged` 调用 `RefreshQrForCurrentAddress`。

### 4.2 v0.14 改造

```csharp
private string BuildDisplayUrl()
{
    var host = LocalAddresses.Count > 0
        ? LocalAddresses[AddressIndex]
        : UploadServerService.GetLocalIpv4Addresses().FirstOrDefault() ?? "127.0.0.1";

    var baseUrl = $"http://{host}:{Port}";

    // 公网 relay 在跑则用公网 URL
    var mode = PublicRelayViewModel?.IsRunning == true && !string.IsNullOrEmpty(PublicRelayViewModel?.PublicUrl)
        ? PublicRelayViewModel.PublicUrl
        : baseUrl;

    return $"{mode}/upload?k={CurrentSecret}";
}
```

> 关键变化：`?token=` → `?k=`，且 QR 内容跟随 `CurrentSecret`（不是当前 `_server.CurrentSecret`，避免启动时序问题）。

### 4.3 同步 RefreshQrForCurrentAddress

`RefreshQrForCurrentAddress` 调用 `BuildDisplayUrl`，所以 `BuildDisplayUrl` 改完即可。无需改 `RefreshQrForCurrentAddress` 内部。

### 4.4 同步 OnPropertyChanged

确保以下变化触发 QR 刷新：

```csharp
partial void OnCurrentSecretChanged(string value) => RefreshQrForCurrentAddress();
// 已有
partial void OnAddressIndexChanged(int value) { ... RefreshQrForCurrentAddress(); }
partial void OnUploadUrlChanged(string? value) { ... RefreshQrForCurrentAddress(); }
partial void OnPortChanged(int value) => OnPropertyChanged(nameof(DisplayUploadUrl));
partial void OnIsRunningChanged(bool value) => OnPropertyChanged(nameof(DisplayUploadUrl));
```

> 全部不动，已有即可。

### 5.3 新增订阅/解绑方法

```csharp
private void SubscribeNetworkChange()
{
    NetworkChange.NetworkAddressChanged -= OnNetworkAddressChanged; // 防重复
    NetworkChange.NetworkAddressChanged += OnNetworkAddressChanged;
}

private void UnsubscribeNetworkChange()
{
    NetworkChange.NetworkAddressChanged -= OnNetworkAddressChanged;
}

private void OnNetworkAddressChanged(object? sender, EventArgs e)
{
    Dispatcher.UIThread.Post(() =>
    {
        IsNetworkChanged = true;
        ErrorMessage = "网络 IP 已变，请重新扫码";
        RefreshQrForCurrentAddress();
        Trace.WriteLine("[UploadServerVM] NetworkAddressChanged, IsNetworkChanged=true, QR refreshed");
    });
}
```

## 风险

| 风险 | 缓解 |
|------|------|
| `NetworkChange` 在 Linux/macOS 上行为差异 | .NET 统一封装，行为一致；如有问题可降级为轮询 |
| `IsNetworkChanged` 与 `ErrorMessage` 同时显示造成视觉混乱 | 黄色条独立区域，逻辑互不干扰 |
| Phase 1 残留 `OnTokenChanged` 未删（service 端已删） | 本 Phase Step 7 grep 检查兜底 |
