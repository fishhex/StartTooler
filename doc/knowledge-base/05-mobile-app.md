# 05 · 移动端 App

星助的移动端 App 让用户把手机拍的照片直接传到 PC 端项目。本文档描述 App 端的业务全景：用户能看到什么、怎么发现 PC、怎么上传、怎么持久化。

## 一、产品定位

**星助 App = PC 端配套的"无线快传"工具**。

不是独立 App，不是手机媒体管理器。**没有 PC 端 = App 不能用**。

类比：

| 类比 | 关系 |
|---|---|
| AirDrop | iOS ↔ iOS |
| **星助 App** | **mobile ↔ PC（StarTooler）** |
| KDE Connect | mobile ↔ PC |

**核心场景**：晚上拍完一组照片 → 回家打开 PC → App 选照片 → 一键传到 PC。

## 二、用户的两个角色

用户既是手机操作者，也是 PC 端操作者。App + PC = 同一用户。

```
┌─────────┐                     ┌─────────┐
│  手机    │  ──── WiFi ────   │  电脑    │
│  App    │                    │  PC 端  │
└─────────┘                     └─────────┘
```

**不支持**：
- 不支持多用户（账号系统）
- 不支持远程访问（跨 VPN / 跨网段）
- 不支持多人协作（同时上传同一项目）

## 三、核心流程

### 3.1 首次连接

```
1. 用户在 PC 端打开"上传与共享" Tab
2. 点"启动服务" → PC 端 HTTP 服务 + UDP 广播
3. 用户在 App 端打开 App
4. App 自动 UDP 扫描局域网（5 秒）
5. 看到 PC 列表 → 选 PC
6. 输入 6 位数字 Token（PC 端 UI 显示）
7. App 试着 GET /api/v1/health
   ├─ 成功 → 进入主页
   └─ 失败 → 提示"PC 不可达"或"Token 错"
8. App 持久化 IP + Token
```

### 3.2 上传照片

```
1. App 主页显示项目列表（is_current=true 的项目优先）
2. 用户选项目
3. App 打开系统图片选择器（iOS PHPicker / Android PhotoPicker）
4. 用户选 1-50 张照片
5. App 调 POST /api/v1/projects/{name}/upload
6. App 显示进度条（按张数）
7. 成功后 → 提示"已传 N 张"
```

### 3.3 后续重连

```
App 启动
  ├─ 读持久化 IP + Token
  ├─ UDP 扫描 5 秒
  └─ 找到匹配 IP → 试探 /api/v1/health
       ├─ 成功 → 直接进主页
       └─ 失败 → 跳到连接页
```

## 五、状态机

App 内有 5 个核心状态：

```
[未连接] ── scan ──→ [扫描中] ── found ──→ [已连接]
   ↑                   │                     │
   │                  no PC                 disconnect
   │                   ↓                     ↓
   └───────── [失败] ←─ no PC ── [已连接] ←──┘
                                   │
                                   validate
                                   ↓
                                [Token 错]
```

| 状态 | 含义 | UI |
|---|---|---|
| 未连接 | 没有持久化 IP 或新装 | 跳到连接页 |
| 扫描中 | UDP 监听 5 秒 | 加载动画 |
| 已连接 | 试探 /health 成功 | 进主页 |
| Token 错 | 401 响应 | Token 验证页 |
| 失败 | 任何错误 | 错误提示页 |

## 六、持久化策略

### 6.1 持久化什么

| 数据 | 平台 | 用途 |
|---|---|---|
| 最近一次 PC IP | iOS Keychain / Android EncryptedSharedPreferences | App 启动直连 |
| Token | 同上 | 跳过 Token 输入 |
| 最近一次 PC 列表 | SQLite / Core Data | 离线展示 |

### 6.2 不持久化什么

- ❌ 媒体文件本身（PC 端是唯一源）
- ❌ 项目目录结构（动态拉）
- ❌ 上传历史（每次实时）

### 6.3 失效处理

| 场景 | 反应 |
|---|---|
| PC 端换了 WiFi | IP 失效 → App 跳到连接页 |
| PC 端 Token 重置 | 401 → 自动清密钥 → 跳到 Token 验证页 |
| PC 端关了服务 | 试探 /health 失败 → 跳到连接页（IP 暂保留） |
| App 卸载 | 全部清理（OS 保证） |

## 七、App 端的能力边界

### 支持

- ✅ 同一 WiFi 局域网内自动发现 PC
- ✅ 手动输入 IP（UDP 抓不到时兜底）
- ✅ 选 1-50 张照片批量上传
- ✅ 上传进度按文件数计
- ✅ 失败部分文件 → 详情展示
- ✅ 持久化最近一次连接
- ✅ Token 失效自动跳验证页
- ✅ iOS Photo Picker / Android PhotoPicker（无需相册权限）

### 不支持

- ❌ 跨路由 / 跨 WiFi（UDP 不跨）
- ❌ 视频上传（PC 端不支持）
- ❌ RAW 上传（PC 端不支持）
- ❌ 拍照直传（暂时；规划中）
- ❌ 浏览 PC 端照片（只传）
- ❌ 多用户 / 账号
- ❌ 远程访问（VPN / 公网桥）

### 暂时不做

- ⏸ 缩略图预览
- ⏸ 离线缓存项目列表
- ⏸ 上传历史
- ⏸ 端到端加密

## 八、App 端 UX 原则

1. **零配置**：安装即用，不需注册 / 配账号
2. **零等待**：所有操作 < 2 秒响应
3. **零失败**：失败明确说明 + 下一步按钮
4. **零权限**：相册走系统选择器，不要相册权限
5. **零后台**：不需要常驻后台 / 通知
